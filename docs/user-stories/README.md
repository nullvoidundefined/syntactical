# User Stories Index

This index lists the user story files for Syntactical, one file per product area, and the ID prefix each file uses.

| Area | File | Story IDs |
|---|---|---|
| Quiz | [quiz.md](quiz.md) | `US-QUIZ-001` to `US-QUIZ-007` |
| Content | [content.md](content.md) | `US-CONTENT-001` to `US-CONTENT-005` |

Each story has an As / I want to / So that statement, an acceptance-criteria checklist, and the test that covers it. The project has no end-to-end suite (owner decision 9), so each story names the component and service tests that cover it instead.
