## Domain vocabulary

One line per domain noun used across this codebase's naming (files, functions, variables, data keys). `language` and `difficulty` are not listed separately: each is already a single, unambiguous identifier (`LANGUAGES`/`language`, `DIFFICULTIES`/`difficulty` in `appConfig.js`) with no competing name anywhere in the code, so there is nothing to settle for them. Do not introduce synonyms for either (`track`, `tier`, `level`, `subject`) as new identifiers.

- bank - the flat array of question objects for one language + difficulty pair (`pythonEasy`, `postgresMedium`, etc.), returned by `getQuestionBank()` - chosen over: `deck`, `pool`, `set` because `getQuestionBank` was the first name committed to the codebase (`src/data/index.js`) and every data file already exports `<language><Difficulty>` (e.g. `pythonMedium`), matching this noun.
- round - one full pass through a shuffled question bank, from the first question to the results screen - chosen over: `session`, `attempt` because `QuizRound`/`useQuizEngine`'s `isComplete` and `ResultsScreen`'s "Retry" already model one bank traversal as a single unit named this way in `QuizView.jsx`.
- query - the per-card explanation of the syntax/method/context behind a question's example, stored on each question object as `question.query` (`{title, syntax, explanation, tags}`) and surfaced through `QueryDrawer` - chosen over: `explanation`, `reference` because the user's original spec named this feature "Query" directly (see `docs/original-prompt.md`, requirement 4), and `QueryDrawer.jsx`/`Card.jsx`'s "Query" button already use the term.
- question - one item in a bank: a single multiple-choice (`type: 'mc'`) or boolean (`type: 'bool'`) card, identified by `id` (e.g. `py-med-01`) - chosen over: `card`, `item` because `question.prompt`, `question.type`, `question.query`, and `useQuizEngine`'s `currentQuestion` already use this noun for the data object; `Card` is reserved for the React component that renders one.
