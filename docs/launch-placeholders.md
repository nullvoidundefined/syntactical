# Launch placeholders

The API can deploy before every secret and setting exists. With `ALLOW_STUBBED_INTEGRATIONS=true` on the Railway service, a missing integration is replaced by a stub that fails closed (owner decision 2026-10-04). Without that variable the server still refuses to start on a missing required variable. This page lists everything that is stubbed or a placeholder and must be replaced before the app is fully runnable. A stubbed deploy is visible: the boot log has one `running with stubbed integrations` line and `GET /health/ready` returns `"stubbed": [...]` with the names. When nothing is stubbed the field is absent.

## Current state (2026-10-30)

- Deployed with stubs: staging and production, both with `ALLOW_STUBBED_INTEGRATIONS=true`. URLs, Neon branches, and ids are in `server/DEPLOY.md`, "Live environments and first-time setup".
- Done: `DATABASE_URL` on both environments, `RAILWAY_TOKEN_STAGING`, `RAILWAY_TOKEN_PRODUCTION`, the PostHog key and host, Resend, `RATE_LIMIT_KEY_SECRET`, `ALLOWED_ORIGINS`, the RevenueCat webhooks and `REVENUECAT_WEBHOOK_AUTH`, the two public RevenueCat SDK keys, the RevenueCat apps, entitlement, offering, and packages, and every row below marked done.
- Still owed: every row below not marked done. In order: the OpenAI key and model for the fallback, the DNS records for `api.syntactical.dev`, the Cloudflare cutover (secrets and Pages project), the AdMob app ids, ad units, and consent message, the EAS builds, the two area 7 decisions, and finally removing `ALLOW_STUBBED_INTEGRATIONS`. The store products and `REVENUECAT_WEB_BILLING_KEY` wait on their own prerequisites (rows below). The EthicalAds publisher id waits for about 50,000 monthly pageviews.

Remove `ALLOW_STUBBED_INTEGRATIONS` once every server row below is real. With it gone, a variable that goes missing later stops the deploy instead of silently stubbing.

## Why each stub fails closed

- No email provider: no email is sent, so no code leaves the server and nobody can sign in. Nothing sensitive is logged.
- No webhook credential: the route is closed (503), never open. An unauthenticated webhook cannot be accepted or recorded.
- No rate limit secret: a random per-boot value, never logged, so counters cannot be forged from a known value.
- No allowed origins: no browser origin passes CORS or the CSRF origin check.
- No EthicalAds publisher id: the web slot shows a direct sponsor or the house card, never an empty or broken card.
- No AdMob ids: development and preview builds show Google test ads or the house card, and a production build stops at config load, so no store build ships without them.
